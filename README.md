# Rock Paper Scissors

A simple **Rock Paper Scissors** mini game built with **HTML and JavaScript**. The game is played for **5 rounds** against the computer.

**Live Demo:** [Play Rock Paper Scissors](https://huynhnhan254.github.io/rock_paper_scissors/?utm_source=chatgpt.com)

This project was built as a small JavaScript practice project to work with functions, user input, conditionals, loops, and basic game logic.

## Features

* Play Rock, Paper, Scissors against the computer
* 5 rounds per game
* Computer randomly selects Rock, Paper, or Scissors
* Tracks the player's and computer's scores
* Displays the final result in the **browser console**
* Simple HTML page with JavaScript functionality

## Technologies

* HTML5
* JavaScript

## How to Play

1. Open the **[Live Demo](https://huynhnhan254.github.io/rock_paper_scissors/)**.
2. Follow the prompts to choose Rock, Paper, or Scissors.
3. Play 5 rounds against the computer.
4. Open the browser's **Developer Console** to view the round results, scores, and final result.

### Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* The same choice results in a tie

After 5 rounds, the player with the higher score wins.
